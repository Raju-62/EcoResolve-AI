# Sustainability Insights Skill

## Goal
Assist with analysis of aggregated EcoResolve complaints.

## Workflow
1. Inspect available complaint data and analytics endpoints.
2. Separate simple numerical statistics from qualitative AI interpretation.
3. Identify recurring categories or locations only when supported by data.
4. Produce concise insight titles, descriptions and suggested interventions.
5. State uncertainty when the data is too small to support a strong conclusion.
