# EcoResolve BOB Rules

1. Use Java 21 and Spring Boot conventions.
2. Keep controllers thin; put business logic in services.
3. Never hard-code passwords, API keys or production secrets.
4. Preserve AI recommendations separately from administrator final decisions.
5. Do not expose admin APIs to students.
6. Validate AI outputs against allowed categories, priorities and statuses.
7. Prefer small, reviewable changes and run tests before accepting generated code.
8. Keep sustainability claims evidence-based and label AI-generated insights.
9. Do not add MCP configuration unless an actual usable server is available.
10. Keep project documentation aligned with the internship's problem, AI role, SDG and responsible-AI requirements.
