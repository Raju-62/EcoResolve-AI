# Suggested Final Presentation

1. Title — EcoResolve AI
2. Problem — sustainability complaints are unstructured and difficult to prioritize at scale
3. Target users — students/staff and administrators
4. SDG alignment — primary SDG 11; secondary SDGs 6, 7, 12
5. Proposed solution — complaint intake + AI analysis + human review + analytics
6. AI role — classification, summarization, priority recommendation and pattern/insight generation
7. Workflow — report → analyze → review → resolve → learn
8. Prototype screens — student dashboard, complaint form, AI result, admin dashboard, insights
9. IBM BOB — development assistant using repository context, Skills, Rules and Plan/Agent/Ask modes; MCP only where genuinely configured
10. Responsible AI — fairness, transparency, ethics, privacy, human oversight
11. Expected impact — faster triage, visibility of recurring issues, better interventions
12. Demo — submit a water/energy/waste complaint and show the admin insight flow
13. Limitations and next steps — replace local AI adapter with approved IBM runtime model, add image analysis, richer hotspot analytics, deployment
