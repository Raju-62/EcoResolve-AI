
# IBM BOB in EcoResolve AI

IBM BOB was used as part of the development process for EcoResolve AI.

The purpose was to use BOB as a development assistant rather than presenting it as the main AI model running the complaint analysis.

## How BOB Was Used

BOB helped during development with tasks such as:

- Understanding the project structure
- Assisting with code development
- Organizing reusable skills
- Following project-specific development rules
- Reviewing and improving development work
